Gmail Aufräumen

Einmalige Einrichtung erforderlich

Google API Zugangsdaten einrichten

Du brauchst eine credentials.json Datei von Google. Das dauert etwa 5 Minuten:

1

Google Cloud Console öffnen

Gehe zu console.cloud.google.com und melde dich an.

2

Neues Projekt erstellen

Klicke oben auf "Projekt auswählen" → "Neues Projekt" → Name vergeben → "Erstellen".

3

Gmail API aktivieren

Suche in der Suchleiste nach "Gmail API" → Auswählen → "Aktivieren".

4

OAuth-Zustimmungsbildschirm konfigurieren

"APIs & Dienste" → "OAuth-Zustimmungsbildschirm" → "Extern" → Name + E-Mail eintragen → Speichern. Dann unter "Testnutzer" deine Gmail-Adresse hinzufügen.

5

OAuth-Client-ID erstellen

"Anmeldedaten" → "Anmeldedaten erstellen" → "OAuth-Client-ID" → Typ: "Desktop-App" → Erstellen → "JSON herunterladen".

6

Datei ablegen

Die heruntergeladene Datei umbenennen zu credentials.json und in den Ordner gmail-cleanup/ legen (neben app.py).

Nach dem Ablegen der Datei diese Seite neu laden.
